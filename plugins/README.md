# プラグインの作り方（席替えし太郎）

プラグインは、`plugins/` フォルダの中の JavaScript ファイルです。`index.html` の `script.js` の次の行に、`<script src="plugins/名前.js"></script>` を足すと、読み込まれます。
読み込む行を消せば、そのプラグインの機能は、ボタンも、設定も、説明も、まとめて消えます。

## 登録のしかた

```js
SekigaeApp.registerPlugin({
    id: "calc",                      // 重ならない名前
    name: "電卓",                    // 設定の「プラグイン」に出る名前
    version: "1.0",                  // 省けます
    description: "電卓を出します。",  // 設定の「プラグイン」の、ⓘの説明（省けます）
    backupKeys: ["calc_mode"],       // バックアップに入れる保存データの名前
    searchWords: "電卓 計算",        // 設定の「さがす」で見つかるようにする言葉
    mount(app) { /* 画面の部品を、スロットに入れる */ },
    ready(app) { /* 本体の準備ができた後の処理 */ }
});
```

## オン・オフ

設定「機能・プラグイン」の「🧩 プラグインの設定」を押すと、設定の画面が開き、読み込まれているプラグインが、グループごとに並びます（グループ分けは、script.js の `SekigaeApp.groups` で決めています。どこにも入っていないものは「そのほか」に入ります）。スイッチでオフにすると、再読み込みのあと、そのプラグインの `mount` と `ready` は呼ばれなくなります（ファイルは読み込まれますが、何も表示されません）。
オン・オフの記録は、バックアップにも入ります。

## 見た目

プラグインの見た目（CSS）は、すべて本体の `style.css` にまとめてあります。プラグインごとに、コメントで区切ってあります。

## 決まり

- 本体の関数や変数は、そのまま使えます（`$id`、`lsGet`、`lsSet`、`showToast`、`isAppLocked` など）。
- プラグインの中の関数名や変数名は、本体と重ならないように、機能の名前を頭に付けます（電卓は `calc` ではじまります）。
- 本体が、プラグインの中の関数を直接呼ぶことは、しません。
- 別のプラグインがないと動かない時は、`registerPlugin` に `requires: ["history"]` のように、前提のプラグインの `id` を書きます。なくても動くけれど、あると便利な時は、`suggests: ["furigana"]` と書きます。設定の「プラグイン」画面に、前提の名前と、オン・オフ・入っていない、が出ます。前提がオフだと、「使えません」と出て、前提をオフにした時には、使えなくなるプラグインの名前が、知らされます。逆に、前提にされている側には、「これを前提にするプラグイン」「これと一緒に使うと便利になるプラグイン」の名前が、オン・オフつきで出ます。

## 記録・統計にタブを足す

```js
SekigaeApp.registerPlugin({
    id: "term",
    name: "学期のまとめ",
    statsTabs: [{
        id: "summary",               // タブの名前（statsTabBtn_summary、statsPane_summary になる）
        label: "🧾 まとめ",          // タブに出す文字
        paneHtml: "<div id=\"statsSummaryBody\"></div>",  // タブの中身のHTML
        render: data => { /* タブを開くたびに呼ばれる。data は記録・統計の集計 */ },
        hideReset: true,             // このタブでは、「記録をリセット」を隠す（省けます）
        hideCsv: true                // このタブでは、「CSV書き出し」を隠す（省けます）
    }]
});
```

タブは、「傾向」と「学期アーカイブ」の間に並びます。プラグインをオフにすると、タブも消えます。

## オン・オフできるプラグイン（本体から切り出したもの）

> この表を直したら、`node tools/sync_plugin_catalog.js --write` で、本体（`script.js`）の一覧に写せます。`--write` を付けずに動かすと、README の表・`plugins` フォルダ・`index.html` の `<script>` 行が、そろっているかを点検できます。

本体（script.js）から、機能ごとに切り出したプラグインです。次の約束で動いています。

- **本体から呼ばれる関数**：プラグインがオフ・ファイルなしのときも、本体が止まらないように、本体にからっぽの関数（スタブ）が残っています。プラグインを登録するときの `stubs: [...]` に、その関数の名前を書きます。オフのときは、スタブに戻ります。
- **画面の部品（HTML）**：index.html に残っています。持ち主のプラグインの名前を `data-plugin="id"` で付けておくと、そのプラグインがオフ・ファイルなしのときに、自動で隠れます。
- **見た目（CSS）**：style.css に残っています。

## 必須のプラグイン（Ver.4.2.0〜）

## 入っていないプラグインの一覧

設定の「プラグイン」の下に、「📦 入っていないプラグイン」が出ます。このREADMEの2つの表（オン・オフできるプラグイン、必須のプラグイン）の `ファイル名.js` のうち、`index.html` から読み込まれていないものを並べます。

- 表は、`| \`ファイル名.js\` | 内容 |` の形で書きます。この形の行だけを読みます。
- `file://` で開いたときは、ブラウザがREADME.mdを読ませないので、`script.js` の `PLUGIN_CATALOG_BUILTIN` の写しを使います。READMEの表を直したら、`PLUGIN_CATALOG_BUILTIN` も同じに直してください。
